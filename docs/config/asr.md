# ASR 配置指南

语音识别（ASR）配置详解。

千问云端模型的设置与命令行使用见 [Qwen-Audio 云端文件转录](./qwen-filetrans.md)。

## 支持的 ASR 引擎

| 引擎 | 特点 | 推荐场景 |
|------|------|---------|
| **FasterWhisper** | 准确度高，支持 GPU 加速与多模型选择 | 本地离线推荐 |
| **Qwen3-ASR** | 阿里开源端到端语音大模型，识别率高 | 本地高质量识别 |
| **MiMo-ASR [API]** | 小米云端语音大模型，识别速度快、成本低 | 云端 API 识别 |
| **Qwen-Audio 云端 ASR [API]** | 千问异步文件转录，返回原生句子与词级时间戳 | 长音频与本地视频的云端识别 |
| **Whisper API** | OpenAI 兼容标准 Whisper 转录服务 | 云端服务 |
| **WhisperCpp** | 轻量级 C++ 实现 | 低配置 CPU 环境 |
| **B接口/J接口** | 在线免配置接口 | 快速测试 |

## 小米 MiMo-ASR [API] 配置说明

VideoCaptioner 集成了小米开放平台最新的 **MiMo-ASR** 大模型语音识别服务（模型 `mimo-v2.5-asr`）。

### 1. 核心特性
- **云端大模型接口**：遵循官方 `chat.completions` input_audio 规范，支持中文 (`zh`)、英文 (`en`) 及自动检测 (`auto`)。
- **自定义 Base URL 保留**：因 Token Plan 与常规 API 服务通道不同，Base URL 需用户手动填写，支持保留所有自定义版本与路由路径（例如官方标准地址 `https://api.xiaomimimo.com/v1` 或 Token Plan 专用地址，系统自动规范化末尾斜杠）。
- **本地 VAD 过滤**：默认开启 Silero，可切换 FireRedVAD；先在本地检测语音，再将超长语音段限制为最多 25 秒提交。全静音音频将产生 0 次 API 调用，静音去除不影响后续语音的时间轴对齐。
- **即时连通性测试**：设置界面提供异步“测试连接”功能，使用内置微小音频探针测试真实的识别端点，错误信息经过敏感信息清洗，绝不泄露 API Key。
- **短字幕与本地强制对齐**：MiMo 官方接口返回原文；本地 Qwen3-ForcedAligner-0.6B 将原文与每个音频段对齐，再用字词时间生成多条短字幕。不会运行本地 Qwen 识别模型或增加 MiMo API 请求。

### 2. 配置步骤
1. 打开 **设置 -> 转录设置**，或在转录主界面选中 **MiMo-ASR [API] ✨** 后点击齿轮图标。
2. 填写 **Base URL**：
   - 填写您开通的服务地址（例如 `https://api.xiaomimimo.com/v1` 或对应渠道的 Base URL）。
3. 填写 **API Key**：
   - 填写您获取的 API 密钥。
4. 检查 **模型**：
   - 默认为 `mimo-v2.5-asr`。
5. **本地 VAD 过滤**（建议保持开启）：
   - Silero 提供语音阈值、最短语音、最短静音和边缘填充；FireRedVAD 提供八项帧级参数（1 帧约 10 ms）。检测所得分段保留原始时间偏移，不重新合并已分开的语音。
   - MiMo 模型与参数独立保存，不改变 Qwen3-ASR 设置；两者共用本地 VAD 模型和运行环境。“准备环境 / 下载模型”仅管理 VAD 组件，无需下载 Qwen 识别或对齐模型。FireRed 模型缺失会明确报错，不自动切换 Silero。
   - 关闭 VAD 后隐藏参数与组件卡片，按原始时间轴固定分块，无需本地 VAD 环境。
   - FireRed 初始值采用[官方非流式基线](https://github.com/FireRedTeam/FireRedVAD/blob/main/README.md)。已有自定义设置保持不变；“恢复默认参数”仅重置 MiMo 的八项 FireRed 参数。
   - 该基线可按音频调整，不代表所有音频的最优设置。[asr.cpp](https://github.com/hqu-little-boy/asr.cpp) 与 [CrispASR](https://github.com/CrispStrobe/CrispASR/blob/main/docs/cli.md) 的阈值、时长设置有所不同，社区尚无统一默认方案（核对日期：2026-10-04）。
6. 点击 **测试连接**：
   - 验证配置正确性，若提示成功即可开始转录。

| FireRed 参数 | MiMo 默认值 | 对应时长 |
| --- | --- | --- |
| 平滑窗口 | 5 帧 | 50 ms |
| 语音阈值 | 0.4 | — |
| 最短语音 | 20 帧 | 200 ms |
| 最长语音 | 2000 帧 | 20 秒 |
| 最短静音 | 20 帧 | 200 ms |
| 合并静音 | 0 帧 | 不跨静音合并 |
| 边界扩展 | 0 帧 | 不额外扩展 |
| 单次检测最大帧数 | 30000 帧 | 300 秒 |


### 3. RPM 请求调度与服务端 429

MiMo 的[速率限制](https://mimo.mi.com/docs/en-US/api/guidance/rate-limit)按同账号、同模型汇总所有 API Key。软件当前**仅按 RPM 控制本地发送频率**，默认 80 RPM，可在 MiMo 齿轮设置或全局转录设置的“MiMo 请求流控”调整。旧 TPM 配置仅保留兼容，不再产生等待；音频时长、token 估算和响应 usage 均不影响调度。

转录与连通性探针在本进程内按服务地址和模型共用 60 秒滚动请求计数，并保持最小发送间隔 `60 / RPM`。默认 80 RPM 对应 0.75 秒，请求本身的耗时计入间隔；请求耗时已超过 0.75 秒时无需再等待。闲置超过 60 秒后没有历史 RPM 排队。软件无法识别账号，因此相同服务地址、模型的不同 Key 也共用本地计数。

“控制请求频率（本地 RPM）”表示软件正在安排发送时间，并不表示服务端返回了错误。“服务端返回 429”表示实际请求收到 429，当前片段会等待后自动重试。软件仅在实际收到 429 时记录脱敏日志，包含片段序号、尝试次数、等待原因及秒数。

收到 429 后，当前片段最多自动重试 4 次，等待可取消。优先遵守 `Retry-After`（秒或 HTTP 日期）；缺失时按约 30、60、120、120 秒加少量随机余量退避，冷却期限由同地址、模型共享。要求等待超过 10 分钟或返回无效等待值时停止本次任务并提示稍后重试，不提前发送。每次重试计入 RPM；非 429 错误不盲目重试。探针遇 429 只提示“服务可达但限流”，不自动重复调用。重试成功只写入一次当前字幕片段，原始时间轴不变，识别未完成时不缓存部分识别结果。

本地不控制 TPM 不会取消服务端的 TPM 限制。其他应用、其他软件进程和同账号其他 Key 的用量在本进程内不可见，因此仍可能收到服务端 429。

### 4. 本地对齐与短字幕

MiMo 转录现在要求准备 **Qwen3-ForcedAligner-0.6B 对齐模型和共享运行环境**。两处 MiMo 设置中的“本地字幕对齐”可查看组件状态、下载模型、准备环境及选择 CPU / CUDA / auto。只需要对齐模型，不需要 Qwen3-ASR 识别权重。任务开始前检查必要组件，旧识别缓存命中时也需要本地对齐环境。

每个 MiMo 音频段的原文送入本地 ForcedAligner；一个任务只加载一次对齐模型。数字、标点和空白按原文映射保留，对齐词时间加上原段起点偏移，并限制在原音频段内。字幕起止使用实际对齐词的时间范围，不强行延长到 VAD 首尾，也不跨段合并静音间隙。

分组优先考虑标点、停顿和阅读长度：中文目标约 18–26 字，上限约 30 字；英文保留词边界，长度约为中文上限的两倍；通常目标 2–6 秒。快速语音或短句可以短于 2 秒，不为满足显示时长伪造时间。局部零时长或重叠的对齐词合入邻近有效单元，不均分补造字词时间。对齐遗漏原文、无有效时间或单个可信单元无法满足长度／6 秒上限时，明确停止导出，不回退为按字数比例估时。

完整识别原文可缓存，以便本地对齐失败后重试时避免再次调用 MiMo；该缓存不代表字幕任务已经完成。旧缓存中的长原文段也会重新对齐并分组，对齐失败不会导出字幕或缓存伪造的最终时间。取消会终止对齐子进程并清理临时文件。

强制对齐结果仍受识别原文、口音、噪声和对齐模型影响，不等于人工校对的精确字幕。已导出的旧 SRT 不会自动修改；要得到新的短字幕，需要重新生成字幕（可复用已有识别原文缓存）。

## 其他配置参数

### Qwen3-ASR 的 FireRedVAD 默认参数

Qwen3-ASR 与 MiMo 均采用官方非流式基线：平滑窗口 5 帧、语音阈值 0.4、最短语音 20 帧、最长语音 2000 帧、最短静音 20 帧、合并静音 0 帧、边界扩展 0 帧、单次检测最大 30000 帧（1 帧约 10 ms）。默认值在配置、识别任务与隔离运行器中一致。

已有参数保留原值，启动不再自动迁移或重置。若此前使用过调优参数，可在 Qwen3-ASR 专用设置页选中 FireRedVAD 后点击“恢复默认参数”，恢复上述八项官方值；该操作不改变 MiMo、Silero 参数或所选模型。
